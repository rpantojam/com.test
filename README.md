# Despliegue
Para desplegar el proyecto se debe tener en cuenta los siguientes pasos:
* Tener MySQL instalado.
* Crear la base de datos prueba t, con usuario root contraseña root
* Crear la tabla clients con los campos id (pk - ai), first_name, last_name, surname, phone.
* Ejecutar el proyecto mediante el comando mvn clean package -DskipTests
